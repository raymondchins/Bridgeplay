Cara pasang Bridgeplay

Butuh:
- Mac Apple Silicon (M1 atau lebih baru) dengan macOS 26 atau lebih baru.
- Akun admin Mac (installer menulis ke folder Applications).
- Internet (installer mengunduh Bridgeplay dan, kalau perlu, Steam; setup
  mengunduh Rosetta dan engine WineCX, sekitar 440 MB).

1. Klik dua kali "Install.command". macOS akan memblokirnya karena belum
   ditandatangani Apple. Klik Done.
2. Buka System Settings > Privacy & Security. Scroll ke bawah sampai bagian
   Security, lalu klik "Open Anyway" di samping "Install.command".
3. Klik "Open Anyway" sekali lagi, lalu konfirmasi dengan password Mac atau
   Touch ID. Installer berjalan di jendela Terminal. Kalau Steam belum ada,
   installer mengunduhnya langsung dari Valve.
4. Bridgeplay terbuka dengan Setup Assistant. Ikuti saja:
   - Your Mac: klik Install di Rosetta kalau diminta (minta password Mac).
   - Graphics: sudah otomatis, klik Continue.
   - Steam: login ke akun Steam kamu.
   - Set Up: klik Set Up. Setup mengunduh engine WineCX. Kalau diminta izin
     App Management, nyalakan Bridgeplay di jendela Settings yang terbuka.
     Setup lanjut sendiri.
5. Klik Open Steam, pilih game Windows, Install, Play.

Update dari NotProton atau Bridgeplay lama yang masih memakai folder
"notproton": saat pertama dibuka, Bridgeplay memindahkan file-nya dari folder
itu ke "bridgeplay" dan menyimpan backup. Tutup Steam dan game dulu; Bridgeplay
menunggu sampai keduanya tertutup.

Controller: pertama kali controller dipakai, Steam minta izin Input
Monitoring. Klik Allow (atau nyalakan Steam di System Settings > Privacy &
Security > Input Monitoring).

Lisensi: Bridgeplay gratis dan non-komersial, berlisensi GPL-3.0 (lihat
LICENSE dan NOTICE). Installer ini menyertakan redistributable Game Porting
Toolkit milik Apple (folder gptk) tanpa diubah, di bawah lisensi Apple
sendiri, yang ada di GPTK-License.rtf.
DXMT dan DXVK (folder cache) memakai lisensinya sendiri, ada di file LICENSE.*
dan COPYING.LIB.dxmt di sini.
